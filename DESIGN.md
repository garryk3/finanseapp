# DESIGN.md — FinanseApp (Flutter, Material 3, RU)

Единый источник дизайн-токенов и визуальных правил для финансового приложения
(RU-локаль, кросс-платформа Android/iOS).

Статус: **черновик** — актуализировать по образцу полного `DESIGN.md`
(принципы → палитра → типографика → компоненты → графики → доступность)
на первой UI-задаче, до ревью агентом `design-reviewer`.

---

## 1. Принципы (обязательны)

1. **Semantic-токены, никаких произвольных hex вне ролей.** Все цвета берутся из
   `ColorScheme` (роли Material 3) либо из констант, объявленных в этом документе.
   Прямые hex в коде разрешены только при инициализации seed-цвета в
   `ColorScheme.fromSeed` и в константах серий графиков.
2. **Красный — только для ошибок и деструктивных действий.** Расход/убыток не
   равен ошибке: для негативных денежных значений используется отдельная
   семантическая роль (например, `tertiary`-подобная), а не `error`.
3. **Роли M3 не перекрашиваются.** `primary`, `tertiary`, `error` и
   поверхностные роли остаются ролями `ColorScheme`.
4. **Контраст проверяется парой (foreground + background).** Минимум по WCAG 2.2:
   текст 4.5:1 (AA), крупный текст и UI-элементы 3:1.
5. **Все значения вычисляются**, не берутся «из головы»: M3-схема генерируется
   `ColorScheme.fromSeed` (tonal spot), контрасты — по формуле WCAG.

## 2. Сид-цвет

Пока не утверждён. Кандидат: `#2E7D32` (зелёный, ассоциация с финансами/ростом) —
заменить решением владельца при первой UI-задаче, зафиксировать здесь
полную палитру (light + dark) по образцу референсного проекта.

## 3. Обязательные разделы полной версии

- Базовая M3-палитра (light/dark, hex + OKLCH, справочно).
- Семантические роли проекта (доход/расход/перевод, статусы операций).
- Типографика (стили темы, допустимые размеры на экран).
- Компоненты и паттерны (карточки счетов, списки операций, формы ввода).
- Цвета серий графиков (`ChartSeriesColors`) и токены сетки.
- Правила доступности (контрасты, touch targets ≥48dp, text scaling).
- Анти-«AI slop»: никаких бессмысленных градиентов и декоративных стеклянных
  карточек; акцент точечный.

## 4. Связь с кодом

- Токены темы — в `lib/app/theme/`; хардкод цветов/стилей за его пределами —
  находка дизайн-ревью.
- Базовые компоненты — в `lib/uikit/`; сырые Material-виджеты запрещены вне
  `lib/uikit/` (analyzer-плагин `restrict_raw_flutter`, см. `AGENTS.md`).
- Все видимые строки — через `lib/l10n/app_ru.arb`.
