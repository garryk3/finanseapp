«Как запустить тестировщика» в `AGENTS.md`). Файл **накопительный**: прошлые
записи не удаляются и не переписываются; новый прогон = новые `TC-*`.

фактический результат и статус: `PASS` / `FAIL` / `SKIP` / `BLOCKED`.

### TC-005 Валидация формы счёта — PASS (с замечанием)

- **Шаги:** (а) сохранить форму без названия; (б) без банка; (в) без начального баланса; (г) баланс `999999999999999999999`.
- **Ожидание:** осмысленные ошибки, сохранение блокируется, без крашей.
- **Факт:** (а) «Введите название счёта.»; (б) «Выберите банк.»; (в) «Введите неотрицательную сумму в основных единицах.»; (г) та же ошибка, переполнения/краша нет.

### TC-175 «Сбросить фильтры» при прокрученных чипах: активный чип виден — FAIL

- **Шаги:**
  1. На странице детализации свайпом влево прокрутить строку чипов до «Всё время».

- **Факт:** строка чипов остаётся в правом положении; активный «Месяц» — узкая
